# Level 0 atmosphere preview

Finite Minecraft Java Edition 1.21.11 world: approximately 144 × 128 blocks, 32 connected rooms.

Download `Level0-Atmosphere-Java-1.21.11.zip`, extract it, and copy the `Level0_Atmosphere_1.21.11` folder into your launcher's `saves` directory while Minecraft is closed. The included Japanese README explains setup.

Char1ie's Backrooms resource pack is not bundled; enable an appropriate original version separately. This archive includes no third-party resource-pack assets.

Anvil/NBT data, block states, walkable connectivity, enclosure, and lamp power were checked programmatically. In-game loading and rendering have not been verified.
